# Courses & Curriculum

## Full Stack Python Development
- **Course Overview:** Comprehensive career-oriented training covering frontend, backend, database, and real-world project deployment.
- **Duration:** 4 to 6 months (Structured hands-on curriculum).
- **Target Audience:** Freshers, non-IT graduates switching to IT, and software job seekers.
- **Curriculum / Technologies Covered:**
  - **Frontend:** HTML5, CSS3, JavaScript (ES6+), React.js, Tailwind CSS.
  - **Backend:** Python, Django / FastAPI, REST APIs.
  - **Databases:** PostgreSQL, MySQL.
  - **Tools & DevOps Basics:** Git, GitHub, Docker basics, Linux commands, Postman, AWS deployment basics.
- **Projects Built:** Full-stack eCommerce application, Student management portal, RESTful API microservice.

---

## Full Stack MERN Development
- **Course Overview:** Complete JavaScript stack training for modern web and SaaS application development.
- **Duration:** 4 to 6 months.
- **Target Audience:** Recent engineering graduates, MCA/BSc students, career switchers.
- **Curriculum / Technologies Covered:**
  - **Frontend:** HTML5, CSS3, JavaScript, React.js, Redux Toolkit, Next.js basics.
  - **Backend:** Node.js, Express.js, JWT Authentication, RESTful APIs.
  - **Database:** MongoDB, Mongoose, Redis caching basics.
  - **Tools:** Git, GitHub, Postman, Docker, Vercel/Render deployment.
- **Projects Built:** Social media platform, Real-time chat application with WebSockets, Job portal.

---

## Learning Modes
- **Offline Classroom:** In-person interactive training with dedicated mentors, daily lab sessions, and direct guidance.
- **Online Live Training:** Live interactive sessions with mentors, recorded session access, and daily doubt resolution.
